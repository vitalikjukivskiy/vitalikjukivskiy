## 👨‍💻 Про мене та навички

Мій напрям — **технічна підтримка, системне адміністрування, діагностика та автоматизація**. Працюю з технічними проблемами, документую рішення та розвиваю власні інструменти й сайти. Для розробки також використовую AI-асистентів; комерційний досвід не прирівнюю до всього стеку особистих проєктів.

| Напрям | Практика та інструменти |
|---|---|
| **IT Support / IT Operations** | Підтримка користувачів, обробка заявок, пошук причин збоїв, документація |
| **Windows & macOS** | Налаштування Windows; діагностика macOS, CrossOver / Wine, сумісність та локалізація |
| **Мережі та моніторинг** | Базова TCP/IP-діагностика, мережеві проблеми, Zabbix |
| **Автоматизація** | PowerShell / Bash на рівні практичних сценаріїв, AI-assisted workflows |
| **Git та релізи** | GitHub, гілки, збірки, релізи, оновлення, GitHub Actions та Pages |
| **Вебпроєкти** | HTML, CSS, JavaScript, Node.js, інтеграції Supabase / Edge Functions у власних проєктах |
| **Документація** | Інструкції, troubleshooting-гайди, відтворювані кроки вирішення проблем |

**Цікавлять ролі:** IT Support L2/L3 · System Administrator · Infrastructure / IT Operations · Automation-oriented Support.

**Мови:** українська — вільно; англійська — A2.
